# Mazebomber Docs

Esta é a pasta pronta do seu site. Para usá-la:

1. Extraia o conteúdo deste `.zip`.
2. Delete a sua antiga pasta `mazebomber-docs` que estava com erro.
3. Coloque esta nova pasta `mazebomber-docs` no mesmo lugar.
4. Abra o terminal nela, rode `npm install` (para baixar os pacotes necessários).
5. Rode `npm run start` para ver o site funcionando.
